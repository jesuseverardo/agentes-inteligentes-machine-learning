# Agentes Inteligentes - Machine Learning

Este repositorio contiene prácticas desarrolladas en Python para la materia de Agentes Inteligentes, enfocadas en algoritmos de aprendizaje supervisado.

## Descripción

El proyecto incluye implementaciones de algoritmos de Machine Learning utilizados para clasificación de datos.  
Los algoritmos trabajados son KNN, SVM y Árboles de Decisión.

## Algoritmos incluidos

- KNN
- SVM
- Árboles de Decisión

## Tecnologías utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
